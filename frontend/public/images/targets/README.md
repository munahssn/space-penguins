# Popular finds pictures

One square picture per card on the start page. Use these exact names (JPG):

- barnard.jpg (Barnard's Star)
- eps-indi-b.jpg (Epsilon Indi B)
- wise0855.jpg (WISE 0855−0714)
- rw-aur.jpg (RW Aurigae)
- r-dra.jpg (R Draconis)

About 600 × 600 px is plenty. A card without a picture shows a dark star field instead.
